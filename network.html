Network Engineering

หน้าความรู้สำหรับเรียนรู้ระบบเครือข่าย ตั้งแต่พื้นฐานจนถึงการทำงานร่วมกับ Server และบริการออนไลน์

🏠

LAN

เครือข่ายภายในพื้นที่ เช่น บ้าน โรงเรียน หรือสำนักงาน

🏙️

MAN

เครือข่ายที่ครอบคลุมพื้นที่ระดับเมืองหรือพื้นที่ขนาดใหญ่

🌍

WAN

เครือข่ายที่เชื่อมต่อพื้นที่ห่างไกล เช่น สาขาและศูนย์ข้อมูล

🔗

VPN

แนวคิดการเชื่อมต่อเครือข่ายผ่านช่องทางเสมือนที่มีการป้องกัน

🖧

Server

ทำความเข้าใจ CPU, RAM, Storage, Virtualization และการให้บริการ

🛡️

Network Security

แนวคิดพื้นฐานด้านความปลอดภัย การแบ่งเครือข่าย และการควบคุมการเข้าถึง
